# เกลือ TCG — HTML / CSS / JavaScript แบบแก้ไขได้

หน้าเว็บใช้ HTML/CSS/JavaScript ไม่มี framework หรือขั้นตอน build ส่วน Gemini ใช้ Node.js 22 ขึ้นไป หรือ Cloudflare Pages Functions

## โครงสร้าง

```
index.html       โครงหน้าและข้อความทั้งหมด รวม <template> ของรายการซ้ำ/ป๊อปอัป
style.css        สี ตัวอักษร ระยะห่าง และหน้าจอมือถือ
data.js         สินค้า ราคา สต็อก รูป รอบเล่น จำนวนโต๊ะ และตารางกิจกรรม
script.js        การค้นหา ตะกร้า จองโต๊ะ และยกเลิก
                 รวมหน้าแชทช่วยเลือกและ Dashboard ยอดขายตัวอย่าง
functions/api/chat.js  ตัวอย่าง API ฝั่งเซิร์ฟเวอร์สำหรับ Gemini บน Cloudflare Pages
assets/          รูปสินค้า โลโก้ร้าน โลโก้เกม โปสเตอร์
favicon.svg      ไอคอนแท็บ
README.md        คู่มือไฟล์นี้
```

## เริ่มแก้ไข

1. แตก ZIP แล้วเปิดโฟลเดอร์ `kluea-tcg` ใน VS Code หรือโปรแกรมแก้โค้ดที่ใช้
2. เปิด `index.html` ในเบราว์เซอร์เพื่อดูเว็บ หรือใช้ Live Server
3. แก้ไฟล์ที่ต้องการ กด Save แล้วรีเฟรชเบราว์เซอร์

หน้าพรีวิวใช้ดูผลลัพธ์ หากต้องการแก้เนื้อหาให้เปิดไฟล์ในโปรแกรมแก้โค้ด
ไม่ต้องแก้ผ่าน Inspect Element เพราะการแก้แบบนั้นไม่ถูกบันทึกลง source

ถ้าต้องการเปิดผ่าน Python ให้รันในโฟลเดอร์ที่มี index.html:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

แล้วเปิด http://127.0.0.1:4173/
การเปลี่ยนพอร์ตหรือเปิดแบบ file:// จะเป็นพื้นที่บันทึกข้อมูลคนละชุดกับพรีวิวเดิม

## แก้อะไรที่ไฟล์ไหน

| ต้องการแก้ | ไฟล์ / จุดที่แก้ |
|---|---|
| ข้อความต้อนรับ ชื่อร้าน เมนู ลิงก์ติดต่อ แชท และ Dashboard | `index.html` |
| โลโก้เกม | `index.html` ส่วน `.brand-strip` และไฟล์ใน `assets/` |
| ข้อความปุ่ม รูปแบบการ์ดสินค้า ป๊อปอัป | `<template>` ท้าย `index.html` |
| สีน้ำเงิน / ฟ้า / พื้นหลัง | `style.css` ส่วน `:root` |
| ขนาด/ช่องว่าง/การจัดหน้า | `style.css` แต่ละหมวด มีคอมเมนต์หัวข้อ |
| หน้าจอมือถือ | `@media` ช่วงท้าย `style.css` |
| เพิ่มสินค้า ราคา สต็อก รูป รายละเอียด | `data.js` → `products` |
| จำนวนโต๊ะ / จำนวนที่นั่ง / เวลา / วันปิด | `data.js` → `booking` |
| โต๊ะที่เต็มเริ่มต้นในเดโม | `data.js` → `booking.occupiedByHour` |
| ตารางกิจกรรม / โปสเตอร์ / คำบรรยายวันที่ | `data.js` → `events` |
| โปรโมชันและยอดขายสำหรับ Dashboard/แชท | `data.js` → `products[].promotion`, `sales.orders` |
| การทำงานของปุ่มและระบบ | `script.js` แบ่งตามหมวด |

## Chatbot และ Gemini (ตัวเลือกเมื่อโฮสต์บน Cloudflare Pages)

หน้าแชททำงานแบบ RAG สำหรับข้อมูลเดโม: ก่อนตอบจะค้นเอกสารสินค้า/โปร/ยอดขายที่ส่งออกจาก Excel, สถานะโต๊ะแต่ละโต๊ะในแต่ละรอบที่สร้างสดจากเว็บ และตารางกิจกรรม ด้วยการจัดอันดับคำค้นไทย/อังกฤษและ character n-gram แล้วส่งเฉพาะผลค้นกับประวัติการคุยให้ Gemini

หากต้องการให้ Gemini ช่วยเรียบเรียงคำตอบ ให้ deploy โฟลเดอร์นี้เป็น Cloudflare Pages แล้วตั้ง `GEMINI_API_KEY` เป็น **secret ฝั่งเซิร์ฟเวอร์** ในหน้า Settings → Variables and Secrets จากนั้น `/api/chat` จะพร้อมใช้งาน (เปิด/ปิดได้ที่ `data.js` → `chat.useGemini`) อย่าใส่ key จริงใน HTML, JavaScript, Excel หรือ GitHub และอย่านำ key ที่เคยส่งในแชทกลับมาใช้ ให้ยกเลิก key เดิมและสร้าง key ใหม่ก่อน การเชื่อม Gemini ใช้ `generateContent` พร้อมประวัติแชท; การ์ดสินค้าและโต๊ะยังมาจากข้อมูลเดโมในเว็บ

เว็บเป็นไฟล์ static จึงถ้าเปิดผ่าน GitHub Pages อย่างเดียว ส่วนแชท/ร้านค้า/Dashboard และ fallback จะใช้งานได้ แต่ endpoint Gemini ต้องโฮสต์พร้อม Cloudflare Pages Function และตั้ง secret ก่อน

## Dashboard และ Excel

ไฟล์ `data/kluea-tcg-demo.xlsx` เป็นชุดข้อมูลจำลองที่แก้ไขได้ มีหน้า Dashboard, สินค้า, โปรโมชั่น, โต๊ะ และยอดขาย หลังแก้ Excel ให้รัน `python3 tools/export-rag-knowledge.py` เพื่อสร้างดัชนี RAG ใหม่ที่ `assets/knowledge.json` ตัวเลขทั้งหมดเป็น DEMO_SAMPLE

อย่าเปลี่ยน `id`, `data-field`, `data-action` หรือชื่อ template โดยไม่แก้ JavaScript ที่อ้างอิงด้วย
ข้อความภายใน element, class สำหรับตกแต่ง และการจัดวางแก้ได้ตามต้องการ
ตัวเลขสถานะโต๊ะและรายการสินค้าถูกเติมจาก data.js; อย่าแก้เฉพาะข้อความเริ่มต้นใน HTML

## ตัวอย่างแก้สินค้า

หา `"name": "Destined Rivals"` ใน `data.js` แล้วแก้ค่าที่ต้องการ:

```js
"price": 5900,
"stock": 6,
"image": "pokemon.png"
```

- `price` ใส่ตัวเลขบาท ไม่ใส่ `฿` หรือ comma เช่น `4500`
- `stock` เป็นจำนวนเต็มตั้งแต่ 0; ใส่ 0 เพื่อให้สินค้าหมดและปิดปุ่มเพิ่มตะกร้า
- `image` เป็นชื่อไฟล์ที่มีอยู่จริงใน `assets/`
- เพิ่มสินค้าโดยคัดลอก `{ ... }` หนึ่งชุดใน `products` คั่นแต่ละชุดด้วย comma
- `id` ต้องไม่ซ้ำกัน; ไม่ควรเปลี่ยน id สินค้าเดิมหากต้องการเก็บตะกร้าเดิม
- ตัวกรองเกมสร้างตามค่า `game` ของสินค้าโดยอัตโนมัติ

## ตัวอย่างแก้การจอง

```js
tableCount: 8,
seatsPerTable: 4,
minPlayers: 2,
slotHours: 2,
startHours: [14, 16, 18, 20],
defaultHour: 18,
advanceDays: 30,
closedWeekdays: [1]
```

`closedWeekdays`: 0=อาทิตย์, 1=จันทร์ ... 6=เสาร์ ใช้ `[]` หากเปิดทุกวัน
ตั้ง startHours เป็นชั่วโมงจำนวนเต็มเรียงจากน้อยไปมาก โดยรอบไม่ซ้อนกันและไม่ข้ามเที่ยงคืน
`defaultHour` ต้องอยู่ใน startHours และ minPlayers ต้องไม่มากกว่า seatsPerTable
occupiedByHour เป็นรายชื่อหมายเลขโต๊ะที่ไม่ว่างในแต่ละรอบ เช่น `18: [2, 3, 5, 8]`
แก้ค่าเหล่านี้แล้วผังโต๊ะ ตัวเลือก และสรุปจะเปลี่ยนตามข้อมูล
หากเปลี่ยนวันปิด อย่าลืมแก้ข้อความแจ้งวันปิดในหน้ากิจกรรมด้วย

## ขอบเขตเดโม

ราคา สต็อก โต๊ะ และรอบเล่นเป็นข้อมูลตัวอย่าง ไม่มีการรับเงินหรือส่งคำสั่งซื้อ/การจองไปยังร้าน
ตะกร้าและการจองเก็บใน localStorage เฉพาะเบราว์เซอร์นี้ ไม่ใช่ฐานข้อมูลร่วมหลายอุปกรณ์
ยังไม่มีระบบหลังบ้าน บัญชีสมาชิก หรือการตรวจสอบการจองชนกันบนเซิร์ฟเวอร์
การเปิดแบบ file:// ใช้ทดลองหน้าเว็บได้ แต่เบราว์เซอร์บางตัวอาจจำกัดการเก็บข้อมูล
ฟอนต์โหลดจาก Google Fonts; หากออฟไลน์จะใช้ฟอนต์สำรองในเครื่อง

## เปิดแชท Gemini บนเครื่อง (รูปแบบเดียวกับ JR)

1. ใช้ Node.js 22 ขึ้นไป แล้วเปิด Terminal ในโฟลเดอร์นี้
2. รัน `cp .env.example .env` เฉพาะครั้งแรก จากนั้นเปิด `.env` และเติม `GEMINI_API_KEY` ของคุณ
3. รัน `npm start` (ไม่ต้อง npm install เพราะใช้เฉพาะ Node built-ins)
4. เปิด http://localhost:4174 แล้วเลือกแชทช่วยเลือก

ป้าย GEMINI หมายถึงข้อความล่าสุดได้รับคำตอบจาก Gemini ส่วน DEMO หมายถึงใช้คำตอบสำรอง ยังไม่ได้ทดสอบ key จริงจนกว่าจะตั้งค่า ตัวบอทคุยจากประวัติ แยกข้อความเป็นบับเบิล และแนบรูปสินค้าที่พูดถึง โดยค้นข้อมูล Excel ก่อนส่งให้โมเดล รุ่นโมเดลเปลี่ยนได้ที่ GEMINI_MODEL

ปรับโทนภาษาที่ `functions/api/chat.js` ส่วน systemInstruction และจังหวะ/การ์ดใน `script.js` ส่วน answerChat
ยังไม่เชื่อม Facebook, Instagram หรือ LINE สถานะการจองยังเป็นเดโมในเบราว์เซอร์

## ข้อมูลสินค้าอ้างอิงสำหรับแชท

แก้ `data/chatbot-products.xlsx` ชีต `สินค้าแชทบอท` เพื่อเปลี่ยนสินค้า ราคา สต็อก โปร รูป และคำเรียกภาษาไทย แล้วบันทึกไฟล์

รัน `python3 tools/export-chat-products.py` ในโฟลเดอร์โปรเจกต์ แล้วรีเฟรชเว็บ สคริปต์จะตรวจข้อมูลและอัปเดต `assets/product-reference.json` ไม่ต้องแก้ JSON เอง และไม่ต้องรีสตาร์ทเซิร์ฟเวอร์

ยอดขายยังอิง `data/kluea-tcg-demo.xlsx` และใช้ `python3 tools/export-rag-knowledge.py` แยกต่างหาก
หน้าร้าน/ตะกร้ายังใช้ data.js หากเปลี่ยนราคาต้องปรับหน้าร้านให้ตรงกันด้วย ข้อมูลทั้งหมดเป็นเดโม

## สินค้าจำลองที่อิงจากคลิปร้านเกลือ TCG

เพิ่ม OP13–OP17, ซองใส่การ์ด, แฟ้มเก็บการ์ด และการ์ดใช้งานคัดเลือกในหน้าเว็บและ `data/chatbot-products.xlsx` อิงประเภทสินค้าที่กล่าวถึงใน https://www.youtube.com/watch?v=YM4ZSiVY1QE ช่วง 11:00–11:58 และ 14:54–15:55 ภาพกล่อง OP13–OP17 เป็นภาพสินค้าตรงรุ่นจากเว็บไซต์ ONE PIECE CARD GAME ทางการ โดยมี URL อ้างอิงใน `data.js` (`imageSource`) และในรายละเอียดของ Excel ภาพซองและแฟ้มเป็นภาพตัวอย่างรุ่นจากผู้ผลิต ไม่ใช่การยืนยันว่าร้านมีรุ่นในภาพ ส่วนการ์ดแยกยังใช้กราฟิกเดโมเพราะไม่ได้ระบุชื่อการ์ดเฉพาะ ราคาและสต็อกยังเป็นค่าจำลอง ยกเว้นแนวคิดการ์ดใช้งาน 10 บาทต่อใบที่คลิปกล่าวถึง รายการใหม่ยังไม่มียอดขายจริงใน Dashboard
